# Security Policy

## Audit Status Disclaimer
**This protocol is currently in active development / testnet phase and un-audited.** Do not use in production with real funds or critical systems until a formal audit has been completed.

## Reporting a Vulnerability
We practice responsible disclosure. If you discover a security vulnerability within AttestFlow, please do not disclose it publicly.

Instead, please send an email to:
**security@attestflow.org**

We will respond promptly and coordinate a fix.
